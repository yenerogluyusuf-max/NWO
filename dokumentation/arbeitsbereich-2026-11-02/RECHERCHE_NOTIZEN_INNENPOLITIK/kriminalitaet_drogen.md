## 7. Für die Simulation: Problemketten, Maßnahmen, Wählergruppen, Regionen

> Als Spielmechanik-Entwurf formuliert (Wirkungsannahmen sind Design-Parameter, keine empirischen Kausalbeweise).

### Typische Problemketten (Democracy-4-artiges Problemnetz)

1. **Jugendarbeitslosigkeit → Synthetik-Drogen (billig, verfügbar) → Kriminalität → Wählerdruck.** Datenbasis: Ereignisse 311.793 (2025), 557 Drogentote (+30 %), 123 Mio. synthetische Tabletten; Kinder im Justizsystem 180.000/Jahr.
2. **Gefängnisüberfüllung (142 %) → Gesundheits-/Rechtsprobleme → Justizreform-Druck → Infazpakete → kurze Entlastung, Rückfall in Wachstum.** Datenbasis: +136 % Auslastung 2015–2025, +29 % Inhaftierungsanstieg 2024/25, Pakete 19.800/38.057 Entlassungen ohne Kapazitätswirkung.
3. **Niedrige Anzeigequoten (sex. Belästigung 11 %) → Dunkelziffer → Politik misst an Meldungen statt an Realität → KADES/Anreize zur Meldung erhöhen registrierte Kriminalität kurzfristig.**
4. **Illegale Waffen (>25 Mio.) → Tötungsdelikte/Schüsse → „Sicherheits"-Thema-Wahlkampf → Waffenrazzias (64.372 in 2026) als sichtbare Maßnahme.**
5. **Cyberbetrug (3,5 % Opfer) → Medien-/Wählerdruck in Großstädten → Kapazität bei Sibereinheiten; oft gegen Drogenbudgets konkurrierend.**
6. **Afghanistan-Opiumrückgang → Synthetik-Shift → Metamphetamin/Arzneimittelschmuggel → neue Behandlungslast (AMATEM-Engpass).**

### Betroffene Wählergruppen

- **Frauen** (häusliche Gewalt, KADES, Frauenmord-Zahlen, Anzeigequoten) — hohe Themensensibilität.
- **Eltern/Familien** (Schulsicherheit, Drogenpräsenz, 180.000 Kinder/Jahr im Justizsystem).
- **Städtische Mittelschicht** (Cyberbetrug 3,5 %, Einbruch, private Sicherheitsausgaben 70 % Stahltür).
- **Grenzprovinz-Bewohner** (Schmuggel, Sicherheitspräsenz).
- **Kleine Gewerbetreibende** (Verbraucherbetrug, Schutzgeld/„çete"-Risiko).
- **Junge Männer** (Haftpopulation 18–40 = 282.931 ≈ 65 % der Häftlinge; Drogenereignis-Tatverdächtige 379.185/Jahr).

### Regionale Schwerpunkte (für 81-Provinz-Modell)

- **Mersin:** Hafen = Kokain-Eintrittspunkt (~50 % Hafensicherstellungen).
- **İstanbul:** Volumen-Täterort (225 Tötungsdelikte 2015, Top); 11 von 16 illegalen Tablettierungszentren 2025.
- **Hatay + 3 Provinzen:** im Drogenbericht 2026 als Schwerpunktregionen („mercek altında") benannt (Antakya Gazetesi 26.09.2026).
- **İzmir/Bursa/Antalya:** Produktion/Tablettierung (je 1–3 Zentren), touristische Hotspots mit Metamphetamin-Thema.
- **Südost/Grenzprovinzen (Syrien/Irak):** Schmuggelrouten, historische Terrorlast (GTI: Grenznähe-Korrelation).
- **Anatolische Kleinstprovinzen:** geringste Tötungsraten historisch (Bayburt 0, Karabük/Çankırı 1 im Jahr 2015) — als „ruhige" Provinz-Defaults.
